Commands are sent only after you press Apply (or Enter). Stop and STOP ALL ramp the output down at the firmware rate (0.25/s), so they are not instant; for an emergency use the HV killswitch. If this page closes, the server aborts tests and stops the motors it was driving within about 1 s. The shaded band on each effort strip is the controller's dead band (motor 1 measured: starts at about ±0.42).
